# Training load dataframe

A dataframe with the training load of 3 subjects.

## Usage

``` r
data("training_load", package = "ACWR")
```

## Format

An object of class `tbl_df` (inherits from `tbl`, `data.frame`) with 84
rows and 5 columns.

## Variables

- ID:

  ID of the subjects

- Week:

  training weeks

- Day:

  training days

- TL:

  training load (arbitrary units)

- Training_Date:

  training dates
